# Math Slayer: Competition Math Toolkit 🎯

A fast, algorithmic Python engine designed to solve challenging competition problems from AMC 8 & many math olympiads. 

## Features
- **Prime Factorization & Divisors**: Computes complete canonical prime factorizations and counts total positive divisors using exponent products.
- **Fast Modular Exponentiation**: Solves large modular powers ($b^e \pmod m$) in logarithmic time.
- **Combinatorics Engine**: Calculates large permutations ($nPr$) and combinations ($nCr$) accurately without floating-point overflow.
